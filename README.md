# Go API — практика backend-разработки

Учебный репозиторий для практики backend-разработки на Go и изучения подходов к проектированию серверных приложений.

Проект развивается постепенно: от простого HTTP-сервера к полноценному API с понятной структурой, конфигурацией, базой данных, авторизацией, обработкой ошибок и тестами.

> Проект создан в образовательных целях и пока не предназначен для использования в production.

## Требования

- Go 1.26.4 или совместимая версия;
- Docker и Docker Compose — если нужна локальная база данных.

## Запуск

1. Клонируйте репозиторий и перейдите в его директорию.

2. Создайте файл `.env` в корне проекта:

```env
HOST=localhost
PORT=8081
TOKEN=development-secret
DSN=postgres://postgres:123789456@localhost:5400/postgres?sslmode=disable
```

Если `PORT` не задан, сервер использует порт `8081`. Остальные переменные пока могут оставаться пустыми.

3. Загрузите зависимости и запустите приложение:

```bash
go mod download
go run ./cmd
```

Сервер будет доступен по адресу `http://localhost:8081`.

Для запуска PostgreSQL выполните:

```bash
docker compose up -d postgres
```
