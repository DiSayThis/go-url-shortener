# URL Shortener

HTTP-сервер для создания коротких ссылок и перенаправления на исходные URL.

Проект находится в разработке: функциональность и API будут постепенно расширяться.

## Запуск

1. Склонируйте репозиторий и перейдите в его директорию.

2. Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

3. Установите зависимости и запустите сервер:

```bash
go mod download
go run ./cmd
```

По умолчанию сервер будет доступен по адресу `http://localhost:8081`.
